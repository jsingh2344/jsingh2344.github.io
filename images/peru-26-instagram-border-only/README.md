# Peru 2026 — border-only Instagram exports

These eight files were created directly from the original photographs referenced by `peru_26.html`.

Only the following export operations were applied:

- honor the source orientation
- resize proportionally to fit inside 1080 x 1350 pixels
- center on a near-black `#0D0E10` canvas
- export as high-quality JPEG

No generative editing, color grading, exposure adjustment, retouching, sharpening, denoising, cropping, or scene modification was applied.

Upload the numbered photographs in order from `01` to `08`. `carousel-preview.jpg` is for review only and should not be uploaded as a carousel slide.
